# HanaBi

基于原神角色创作的 Windows 原生主题界面，包含角色动态背景、专属控件装饰、元素材质和开场动画。目前提供甘雨、八重神子、宵宫、纳西妲、芙宁娜、珐露珊、钟离七个角色，以及独立黑白主题。

使用 C++20、Win32、Direct3D 11、HLSL 和 Dear ImGui。支持主题分类与滚动卡片、字体调节、固定或随机启动主题、窗口缩放及进退场动画。当前以本地 UI 与交互展示为主。

## 构建

使用 Visual Studio 2022，安装“使用 C++ 的桌面开发”、v143 工具集和 Windows SDK。打开 `HanaBi.sln`，选择 `Release | x64` 构建。

产物统一输出到 `bin/Release/hanabi.exe`。字体、纹理和预处理人物动画随工程提供并嵌入程序；构建及运行无需 Python，也不依赖原始壁纸工程。

角色专属内容位于 `src/characters/<英文名>/`；公共 UI、材质与渲染分别位于 `src/ui/`、`src/intro/`、`src/gfx/`。Visual Studio 筛选器同步按角色归类。
