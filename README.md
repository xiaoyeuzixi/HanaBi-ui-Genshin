# HanaBi UI

**以《原神》角色为灵感的 Windows 桌面 UI 项目。**

HanaBi 将角色主题、动态背景与桌面交互结合在一起。每套角色主题都有配套的启动动画、元素标识、界面装饰和窗口按钮，让从打开应用到日常操作的视觉风格保持一致。

目前提供 **甘雨、八重神子** 两套角色主题，以及白色、黑色两种简洁外观。

## 主题与体验

| 主题 | 设计方向 |
| --- | --- |
| 甘雨 | 冰蓝色调、冰晶雪花与中式结饰，搭配角色动态背景 |
| 八重神子 | 樱粉与紫色调、雷元素标识与辉光，搭配角色分层动画 |
| 白色 | 明亮、清晰的浅色界面 |
| 黑色 | 以内容为主的深色界面 |

角色主题围绕人物特征与背景分别设计，涵盖配色、装饰、标识和动画。主题页可以切换外观、调整字号，并设置背景与动画选项。

### 连贯的动画

启动动画与主界面侧栏标识自然衔接，页面切换、控件反馈和窗口最小化、恢复也有配套过渡。动态背景与角色运动共同构成界面的氛围。

### 可记忆的外观设置

支持跟随当前主题启动、指定主题启动，或在角色主题中随机选择。随机模式不包含黑色与白色外观。

主题、字号与启动偏好会自动保存，下次打开继续使用。整体字号支持 **100%–125%** 调节，默认 **112%**。

### 完整的桌面交互

支持窗口拖动、边缘缩放、最大化、最小化、恢复与关闭。界面提供多个功能演示页，包含开关、滑块、选项切换、按键录入，以及极简人物部位选择与预览。

当前项目侧重 **UI、视觉效果与交互展示**，功能页使用演示数据，尚未接入业务后端。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| C++20 | 应用逻辑、资源管理与动画控制 |
| Win32 API | 原生窗口与桌面交互 |
| Direct3D 11 / DXGI | 图形渲染与画面呈现 |
| HLSL | 元素材质、辉光与动态背景效果 |
| Dear ImGui | 界面交互与自定义绘制 |
| stb_image | 图片解码 |
| Windows RCDATA | 将字体、图片与动画资源嵌入程序 |

角色分层动画由 C++ 读取预处理资源并插值播放。所需资源已随源码提供，**编译时无需 Python、资源生成脚本或原壁纸目录**。

## 构建与运行

需要 Windows 10 / 11 x64、支持 Direct3D 11 的显卡，以及安装了“使用 C++ 的桌面开发”的 **Visual Studio 2022**。工具集使用 **MSVC v143** 和 **Windows SDK 10.0**。

1. 打开 `HanaBi.sln`。
2. 选择 `Release | x64`，生成解决方案。
3. 运行 `bin\Release\hanabi.exe`。

也可在 Visual Studio Developer PowerShell 中执行：

```powershell
msbuild .\HanaBi.sln /m /p:Configuration=Release /p:Platform=x64
.\bin\Release\hanabi.exe
```

项目仅包含一个解决方案与一个主程序工程，已按功能配置 Visual Studio 筛选器。编译结果统一使用 `bin\Release\hanabi.exe`，后续构建覆盖同名文件。字体与运行资源均嵌入程序，生成后的 EXE 可单独运行。

## 源码结构

```text
HanaBi.sln                 解决方案
HanaBi.vcxproj             C++ 工程
HanaBi.vcxproj.filters     Visual Studio 筛选器
hanabi.rc                  内嵌资源清单
src/
  assets/                  资源读取与字体加载
  core/                    基础工具与偏好设置
  gfx/                     背景、人物动画与窗口动效
  intro/                   启动动画与元素材质
  ui/                      主题、控件与页面
assets/
  fonts/                   字体与字体子集
  tex/                     图片、效果贴图与人物动画包
third_party/               ImGui 与 stb_image 源码
```

仓库包含直接构建需要的源码、第三方依赖和最终资源；构建缓存、调试文件、预览帧图及本机设置不进入版本管理。

## 使用说明

- 在主题页选择外观、字号与下次启动方式。
- 拖动窗口顶部移动位置，拖动边缘调整大小。
- 使用右上角按钮进行最小化、最大化或关闭。
- 启动动画期间按 `Esc` 可跳过。
- 外观设置保存在 `%LOCALAPPDATA%\HanaBi\settings.ini`。
