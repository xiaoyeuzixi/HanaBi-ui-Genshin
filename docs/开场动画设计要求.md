# HanaBi 角色开场动画设计要求

记录日期：2026-10-21。本文记录用户明确提出的要求，作为后续开场动画修改和验收的依据。

角色专属代码、设计说明及资源入口见 [角色主题索引](角色主题索引.md)。每个角色的 UI、开场和设计文档集中在以英文名命名的对应目录中；公共材质与控件继续共用。

## 核心目标

动画要惊艳、精致、极其丝滑，也必须和角色、背景、元素材质相协调。最重要的是，观众应当能看懂前一阶段的物体或能量，怎样连续地成为最终元素图标。

不能用“先播放一些特效，随后把完整图标淡入、放大”来代替成形过程。用户反复指出目前五个重做版本仍有突然显示、衔接突兀的问题。修掉提前显示的辉光只是修复错误，不代表已经满足这个设计目标。

## 已认可的基准

- **钟离 / 岩元素**：岩核降临、打开，实体碎片运动、拼合，连续组成岩元素。用户认可其和谐程度和设计方向。
- **珐露珊 / 风元素**：机关聚合、展开，风能与机关演出共同带出风元素。用户认为其衔接明显优于目前其他重做版本。
- 这两版保留。其他角色应达到同等级别的连续性和完成度，不能把所有角色都套成碎片拼图或沿轮廓描线。

## 成形过程的验收重点

1. **有来源**：最初的小冰晶、雷能、火种、生命种子、水滴，要与最终图标有可追踪的联系。
2. **有连续的物体或能量运动**：轮廓、体积、位置或材质逐渐转换；关键部件必须确实运动到最终位置。
3. **图标不是后来叠上的另一层**：前景、辉光、倒影等所有通道使用同一成形进度。图标尚未成形时，不能先看到一个完整的大轮廓。
4. **过程舒展**：不能突然加速、突然放大、翻一下就结束，也不能在最后一帧把某块直接放到位。
5. **自然定格**：成形末端逐渐减速、收束能量，再保持一小段完整图标的展示。
6. **自然停驻**：同一个图标平滑移动、缩放到左上侧栏 Logo 位置，不能先消失再换一个侧栏图标。

不能只看定格截图。必须检查完整动画、相邻帧以及成形前后与停驻前后的衔接；同时验证中途跳过的过渡。

## 五位角色的具体反馈与方向

### 甘雨

- 保留用户选定的浓蓝色、深层蓝冰与折射质感，不能退回普通透明塑料或浅白发光贴片。
- 冰莲、冰珠、降雪可作为角色演出，但必须和雪花成形连接成一个过程。
- 最新反馈：冰莲、冰珠与雪花之间不和谐，元素像突然显示出来。
- 打磨重点：冰晶自身展开、结晶或转换成雪花，让冰珠和莲瓣的能量在同一中心汇入，避免几件独立物体互相覆盖。
- 保留璃月孔明灯与雪景的氛围。

### 八重神子

- 使用参考图的紫色、淡紫亮芯与紫色辉光，不能改成三色配色。
- 杀生樱、狐灵、樱花和雷纹要做精致，不能用几根廉价的线条冒充完整设计。
- 最新反馈尤其强烈：开局就摆着一个完整的大雷元素，整体不好看，成形突兀。
- 已发现的问题：辉光遮罩忽略了顶点透明度，导致主体尚未显示时，完整图标的辉光已提前出现。此问题必须修复并通过实际渲染检查。
- 打磨重点：让三座杀生樱里的雷能或实体部件连续汇聚、转换为雷元素；不能只在中央淡入完整图标。狐灵是演出辅助，不能抢占主体或变成敷衍的线稿。

### 宵宫

- 保留原神火元素的完整轮廓，包括内部结构。火焰与焰硝要有真实的流动、燃烧和余烬，不能只是贴图拆开再合拢。
- 烟火、金鱼和祭典氛围用于角色差异，火元素本身仍要准确。
- 用户不喜欢整枚图标翻转出场，也不满意普通放大或突然显现。
- 最新反馈：火元素出现不够和谐、不够丝滑。
- 打磨重点：由火种和烟火中的火焰连续形成图标，火舌跟随正在成形的部分。图标与周围火焰的尺寸、位置、时序必须一致。

### 纳西妲

- 保留摩耶之殿 / 大招殿堂的意象。**用户明确要求继续精雕细琢，不是删掉穹顶。**
- 用户不接受简陋的圆弧线框，也不接受仅靠增加线条密度完成设计。
- 打磨重点：叶形建筑轮廓、镂空叶脉、莲瓣层次、通透材质和柔和生命光共同构成梦境殿堂。
- 草元素应从莲心、种子或生命结构中连续展开，不能独立突然显示。

### 芙宁娜

- 用户认为水神当前开场方向较好，保留帷幕、水滴、水上舞台、图标升起的主流程。
- 最新反馈：倒影不够完美，舞台搭建不够好。
- 倒影必须对应同一时刻的实际图标，并符合水面透视压缩、波纹扰动和距离衰减。不能把三角网格大幅扭曲成破碎影子。
- 舞台需要有完整台面、边缘厚度、层次、帷幕及灯光的联系；不能只在图标下面画几条椭圆。
- 水面裁切、上升与倒影必须同步，成形前不能漏出完整图标的辉光。

## 统一约束

- 后续按**角色**选择开场，不只按元素选择；同元素的不同角色可拥有不同演出。
- 元素图标保持原神原有形状和配色，用原生几何与材质绘制，不直接裁剪参考图充当成品。
- 图标下方不加额外文字；右下角统一显示 HANABI 品牌。
- 保留已有主题布局、背景人物动态、主题设置与启动主题记忆。
- 开场沿用 6.20 秒时长和统一侧栏停驻；节奏应在时长内重新编排。
- 所有角色保留流畅的中途跳过功能。
- 程序为原生 C++ / D3D11 实现；完成后编译到同一个 `bin/Release/hanabi.exe`，不逐版堆积产物。
- 未经用户另行授权，不同步到交付目录，不上传 GitHub。

## 当前验收状态

- 风、岩：用户认可，保留。
- 水：主方向认可，舞台、倒影与成形细节仍在打磨。
- 冰、雷、火、草：本轮重做尚未获得用户认可，重点解决成形连续性与精细程度。
- “编译通过”和“测试通过”只证明实现可运行，不能据此宣称视觉效果已经获得用户认可。
