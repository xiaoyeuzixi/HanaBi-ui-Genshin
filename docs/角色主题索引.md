## 公共模块边界

- `src/characters/characters.h/.cpp`：角色开场描述与查找、共享皮肤基础值。
- `src/characters/character_ui.h/.cpp`：角色 UI 绘制接口与分派。
- `src/ui/theme.cpp`：主题注册、黑白基础主题及主题过渡；角色内容由各角色 `MakeTheme()` 提供。
- `src/ui/shell.cpp`：公共布局、导航、主题库筛选滚动、输入和窗口操作。
- `src/ui/theme_ornaments.h/.cpp`：花、金鱼、绳结等可复用绘制基础。
- `src/intro/character_openings.cpp`：公共开场分派、停驻和自检。
- `src/intro/opening_draw.h/.cpp`：通用光晕、光带、莲瓣、珠体等基础绘制。
- `src/intro/*_geometry.h` 与材质文件：可供同元素不同角色复用的元素轮廓和渲染能力。
- `src/gfx/`：背景、人物动态、纹理与窗口运动等通用渲染。
- `assets/tex/`：已预处理资源，以角色名为前缀；Visual Studio 资源筛选器按角色归类，文档列出具体资源入口。

角色文件决定演出与装饰，公共模块负责可复用能力。同元素的新角色可以共用元素材质，但要有自己的 UI 与开场，不能覆盖已有角色实现。

## 新增角色

1. 用稳定的小写英文名或拼音创建角色目录；多词以下划线连接。
2. 添加同名前缀的 UI、开场、设计说明三个文件，记录角色特征、资源来源、分镜及验收状态。
3. 在角色注册与 UI 分派中增加入口，维护主题定义、主题 ID、持久化设置与资源映射。已有主题键和 ID 不随目录整理改变。
4. 将源文件、头文件、设计文档加入 `HanaBi.vcxproj`，并加入对应角色筛选器；资源加入对应角色的资源筛选器。
5. 验证分类筛选、长方形卡片、姓名及短句、滚动、固定或随机启动；随机启动排除黑白主题。
6. 检查完整开场、相邻帧、跳过与侧栏停驻，并回归风、岩两个已认可基准。

## 统一设计与交付要求

完整验收依据见 [UI 设计要求](UI设计要求.md) 和 [开场动画设计要求](开场动画设计要求.md)。所有主题保留可调整字体、默认 112%、通透角色背景、专属窗口按钮和流畅转场。图标下不加额外文字，右下角保留 HANABI。

使用 C++20、Win32、D3D11 和 Dear ImGui；VS 2022 / v143 构建 `HanaBi.sln` 的 `Release | x64`，统一产物为 `bin/Release/hanabi.exe`。预处理资源随项目提供，构建和运行不依赖 Python。交流群：835775657。
